# 项目助理 · 为项目经理打造的本地 AI 交付工作台

> **资料全存本机不泄密 · 杂乱纪要/Excel/群聊秒变清晰行动 · 每句结论都能溯源到原文第几页第几行 · 一键出老板版周报**

基于 **Tauri 2 + Rust + React + SQLite** 构建。没有云端账号、没有订阅费、没有后台埋点——你的会议纪要、客户合同、群聊同步和排期台账全部留在本机设备里；配合自带的国产大模型（DeepSeek / 通义千问 / 豆包 / Kimi / 智谱 / 本机 Ollama），把琐碎的信息整理、卡点催办和汇报写作交给 AI 副驾驶。

---

## 为什么做给项目经理？

| 传统痛点 | 传统表格 / 云协同工具 | 项目助理（本地工作台） |
| --- | --- | --- |
| **信息散落在十几个地方** | 微信群聊、Excel 排期表、PPT 周会、邮件各放各的 | **全格式拖入统一归档**：Word / Excel / PPT / PDF / CSV / EML / 微信聊天粘贴 |
| **通用大模型爱胡说、不保密** | 把公司机密直接喂给网页版 AI，回答还不给依据 | **数据全在本地 + 逐句原文溯源**：每条记忆和回答精准定位到原文页码/段落/表格行 |
| **每天被追进度、忘了谁卡住** | 需要手动翻表格、在几个工具里来回点 | **打开「今日行动流」**：早盘重点、逾期阻塞、待拍板、催办话术一屏点完 |
| **写日报/周报占掉下班前 1 小时** | 对着聊天记录复制粘贴凑字数 | **一秒切换汇报风格**：基于真实记录自动整理，支持老板摘要/团队对齐/客户版及 Word/长图/PDF 导出 |

## 核心功能一览

### 1. 今日行动流 + 早中晚节奏条
打开应用默认进入「今日行动流」，直接回答项目经理每天最关心的 4 件事：
- **今天我要先推进哪几项工作**（按逾期、高优先级、今日排期自动置顶）
- **哪些卡点和事项需要协调/拍板**（附现成催办草稿与跟进记录）
- **哪些项目存在交付延期风险**
- **新导入的聊天和纪要带来了什么变化**

### 2. 全格式办公文件直读（无需企业管理员审批）
把资料**直接拖进应用窗口**或批量导入（单次最多 50 份）：
- **表格 & 演示**：Excel (`.xlsx`)、CSV 排期表、PPT (`.pptx` 含演讲备注)
- **文档 & 邮件**：Word (`.docx`)、可选中文字的 PDF、Markdown、TXT、邮件 (`.eml`)
- **聊天记录 & 录音转写**：直接复制微信、企微、钉钉群聊或腾讯会议/飞书妙记转写文字粘贴导入

### 3. 任务看板 + 里程碑甘特时间轴
- **任务管理**：支持「列表视图」与「4 列拖拽看板（待办 / 进行中 / 阻塞 / 已完成）」，一键导出 Excel 兼容的 `.csv` 台账。
- **里程碑时间轴**：在「项目总览」直观展示任务健康度分布条、今日参考线，以及里程碑**原定基准日 vs 当前预计日**的偏差跨度。
- **全生命周期治理**：内置需求变更审批、交付物验收标准、风险决策台账、会议议程与行动项闭环。

### 4. AI 副驾驶（可查、可改、写入必经你拍板）
- 按 `⌘J` / `Ctrl J` 随时唤出右侧 AI 副驾驶，对话记录自动持久化保存在本机。
- 用大白话下指令（如：*“盘点当前项目延期风险和今天最优先的 3 件事”*、*“把设计稿任务截止日延到周五”*、*“帮我生成今天的工作日报”*）。
- **人工拍板红线**：所有只读查询自动执行；任何新建任务、改排期、记录风险或生成日报的写入操作，**必须弹出确认卡由你点确认才会生效**。

### 5. 一键切换老板版 / 客户版汇报 + 多格式导出
- 日报与周报基于当天/本周**真实的任务进展事件**本地生成，历史版本完整保留。
- 支持 AI 一键切换 3 种受众风格：**老板高管摘要版**、**项目群对齐版**、**客户汇报专业版**（严格禁止编造原稿外的数据）。
- 一键导出：**复制富文本**（直接粘进飞书/企微/Word 保留排版）、**原生 Word (`.docx`)**、**高颜值汇报长图 (`.png`)**、**打印 / 存 PDF** 及 **Markdown**。

### 6. 进阶玩法：飞书个人账号助理（可选）
如果你所在企业支持创建飞书自建应用，可在「飞书助理」绑定指定群聊或同事私聊，支持增量同步群消息与云文档，并在群里有人 `@你` 时按绑定项目的真实证据自动草拟并回复（按已获批权限分级启用，未获批不卡死）。

## 3 分钟极速上手

1. **下载安装或本地体验**：首次启动进入 3 步引导页，支持 **4 套开箱即用行业模板**（互联网版本交付 / 乙方客户实施 / 敏捷双周迭代 / 市场活动筹备）或 **「一键体验示例」**（3 秒生成完整双项目、里程碑时间轴与任务看板，**无需配置任何 API Key**）。
2. **连接国产大模型（推荐，2 分钟）**：打开「工具与设置 → 模型设置」，一键选择 **DeepSeek / 通义千问（百炼）/ 豆包（火山方舟）/ Kimi / 智谱 GLM / 硅基流动** 预设并填入自己的 API Key；如要求完全离线，可选择 **本机 Ollama**。
3. **日常跑起来**：把今天的会议纪要、Excel 排期或群聊记录拖进窗口 → 确认提取出的待办与风险 → 在「今日行动流」推进工作 → 下班前一键切换老板版风格导出周报/日报。

## 隐私与数据安全承诺

- **本地数据归属你**：所有项目资料与数据库均保存在你的电脑硬盘（[查看完整隐私与安全白皮书](PRIVACY.md)）。
- **密钥隔离加密**：API Key 与飞书令牌单独存放于 `secrets/`，支持 macOS / Windows 系统凭据 AES-256-GCM 加密，**绝不写入导出备份**。
- **可控的加密备份**：支持设置定时自动备份，以及使用至少 12 位密码导出 AES-256-GCM 加密的 `.pabackup` 迁移文件。
- **脱敏问题反馈**：应用内「帮助、隐私与反馈」提供一键导出脱敏诊断报告功能，仅含版本号、计数与错误码，绝不泄露项目正文。

## 常见问题（FAQ）

- **Q：使用这个软件需要花钱买会员吗？**
  A：软件本身基于 [MIT 协议](LICENSE) 完全免费开源。如果你连接云端大模型，仅向你选择的模型服务商按实际 Token 支付费用（通常每天几分钱；也可使用 `glm-4-flash` 等免费/低价模型或本机 Ollama 实现零费用）。
- **Q：公司没有飞书，或者公司 IT 不让建飞书应用怎么办？**
  A：完全不影响！飞书连接是可选的进阶能力。日常只需直接拖入 Excel / Word / PPT / PDF，或直接复制微信、企微、钉钉群聊粘贴导入即可。
- **Q：会把公司内部敏感资料传到外面吗？**
  A：不会偷偷上传。未在「模型设置」勾选授权外发前，所有文本均留在本机；对保密要求极高的项目，直接连接本机 Ollama 即可做到 100% 物理断网运行。
