为什么它比「网页 AI + Excel」更适合真实交付？

职场项目最怕两件事：一是把客户/公司资料传到公网，二是 AI 编造进度却找不到依据

传统网页 AI 聊天

  • 每次都要重新复制粘贴背景，聊完就忘
  • 无法理解任务状态变化与历史版本
  • 经常编造日期和负责人，不敢直接发给老板

纯表格 / 在线协同软件

  • 需要全员拉入平台填表，客户/外协根本不配合
  • 会议纪要、微信语音转写、邮件还是得靠手抄
  • 数据存在他人云端，换公司就带不走

项目助理（本地工作台）

  • 不强迫团队换工具：拖入 Excel/PPT/纪要或粘贴微信记录就能跑
  • 结论可溯源：每条事实锚定原文页码/段落，修改有历史可回退
  • 人机拍板机制：AI 帮你查、帮你写，但改任务/发汇报必经你点确认

常见问题与安全顾虑解答

数据存在哪里？会偷偷上传公司资料吗？

全部保存在你电脑本地的 SQLite 数据库中，本软件没有任何自建后端服务器、无登录账号、无埋点统计。只有在你在「模型设置」中填入自己的 API Key 并显式勾选同意发送资料后，才会将当前分析所需的片段发往你指定的模型接口。对机密极高的项目，可使用本机 Ollama 实现 100% 离线断网运行。

一定要接飞书才能用吗？我们公司用微信 / 企微 / 钉钉

不需要！飞书连接只是可选的高阶功能。平常直接把微信、企微、钉钉群聊记录复制粘贴进来，或把 Excel 排期表、Word 纪要、PPT 汇报、PDF、邮件直接拖进应用窗口就能立即开始管理与提取。

接大模型贵不贵？会不会后台悄悄把我余额烧光？

软件完全免费开源，你直接用自己的模型账号按量计费。预设中的智谱 glm-4-flash、硅基流动、阿里百炼新用户均有大量免费额度，DeepSeek 日常提取和问答通常每天仅几分钱；应用内「帮助、隐私与反馈 → AI 用量与隐私」随时可看今日请求次数与预估费用。

换电脑或重装系统怎么迁移？

在「备份与恢复」一键创建备份，可导出标准 ZIP 或至少 12 位密码的 AES-256-GCM 加密备份文件（`.pabackup`），在新电脑导入即可完整恢复所有项目、任务历史、原文依据和日报版本。注意：为了安全，API Key 不会打包进备份里。
