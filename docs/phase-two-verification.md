## 模型协议与记忆流程

协议验收使用 `scripts/mock-model-server.mjs` 提供的确定性 HTTP 测试服务，明确不是真实 AI，也不会进入产品包或成为模型失败时的替代实现。

1. 模型配置保存后读取只返回 hasApiKey；HTTP 测试服务核对 Bearer 认证头，合成连接测试成功。
2. 导入资料自动解析并生成 AI 待确认候选，正式记忆仍为 0；引用的片段 ID 和原文逐字匹配。
3. 编辑候选保留模型/提示/任务/引用来源；显式确认形成正式记忆，重复确认幂等。
4. 再次提取相同资料，在原候选被编辑后也不会重复生成同一 AI 结果。
5. 不存在的引用导致显式失败，没有候选落库；手动重试后可成功。
6. 合法空数组记为成功零候选，与协议错误、依据失败区分。
7. 网络进行中数据库仍可响应；取消状态立即持久化，旧请求迟到后不能写入候选。
8. 进程重启保留候选来源、正式记忆与凭据；凭据不在数据库/备份中，Unix 权限为目录0700/文件0600。
9. 第一阶段真实 ZIP（schema1）可以检查、还原、迁移至 schema2，并保留当前设备凭据和还原前安全副本。

Core 另以确定性现场验证取消→重试的 generation 隔离、配置变更取消旧任务、重启不复活取消任务，以及普通还原/还原中断回滚均暂停 AI。

独立审查曾发现：还原尚未解析完成的导入任务可能重新触发自动 AI。修复后，两条还原路径都会清除恢复导入任务的自动外发标记，并加入“还原后完成解析仍不创建提取任务”的回归测试。

## 真实云端验证边界

自动化测试不代表真实模型提取质量。截至本记录，真实 DeepSeek API Key 未由测试代码提供，云端认证与提取尚待用户在应用内配置后验证。测试用密钥全部为明确的假值，没有从系统其他应用复用或读取用户凭据。

源片段的逐字引用校验只能验证引用存在，语义是否正确仍由用户确认。扫描 PDF OCR、工作清单、日报、语义检索、自动合并正式记忆不属于本阶段。
