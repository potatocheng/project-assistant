# 记忆系统架构优化与20题实测

已完成确认记忆、完整原文段落、完整证据包审查及一次有界修订的整合。主要收益在桌面问答，连接器尚未获得稳定提升，token消耗明显上升。

模型为 deepseek-flash；同一批20题含19题可答与1题无答案。旧答案与新答案在同次匿名评分中比较，另保留旧原评。

| 问答tokens | 312,132 | — | 835,565（+167.7%） |

桌面配对新增成功5题、退化0题；连接器新增成功与退化各1题。完整原文有助于阅读，但不计为新正式记忆。本次未重新提取，留存不变不能解释为提取提升。

两次开发集尝试全部保留，合计307次真实请求、2,671,249 tokens，其中问答1,588,649、评分1,082,600。最终一次为156请求、1,382,741 tokens。

第二次运行中，旧校验器将一条合法的当前项目元数据误当作记忆而中止；冻结资料核对后，仅在独立派生结果中补正3个校验字段。另4个因并发预算预留而尚未发出的评分阶段，在原预算内串行完成首次调用。没有重新生成已完成答案，没有重新评价已完成评分，也没有扩大预算。原始中止快照、收据前缀、续跑脚本和校验补正均有哈希记录。

最终472项Rust测试通过（5项忽略）；原242项脚本测试及新增18项离线审计测试通过；Clippy、前端类型检查、模型二进制构建通过。最终审计核对了40个问答来源、60个评分阶段、929条冻结记忆及全部提供方usage。

这是已知开发集的同模型自动评分；部分题存在答案范围或推断口径差异，不能据此推断新问题上的准确率。本轮尚未执行完整100题评测或其中80题留出集评测。
