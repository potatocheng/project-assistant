## 使用入口与边界

左侧“待处理”集中处理到期记忆与候选；“项目问答”保存会话和收藏；“搜索 Ctrl K”跨记录检索。“设置与工具”提供质量评估、桌面运行与数据保护、项目归档与资料版本管理。

自动备份和系统提醒默认关闭，需在设置中开启。自动备份仅在应用运行时执行，清理范围仅限本程序记录的自动副本；本地自动副本仍为 ZIP，离机保存可使用密码加密导出。系统凭据保护绑定系统账号及工作区路径。周报与会议草稿按记录版本隔离，旧版本草稿仍可从历史版本查看。
