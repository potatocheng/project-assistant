# 今日概览与 AI 任务推进

配置可用的 AI 模型后，今日概览会自动生成「今天先做这些」。默认展示最多3个重点及各自的一句话行动；判断理由、逐字引文和完整行动放在「分析与依据」中。额外风险、补充行动、待确认问题及分析范围按需展开，避免三列长文重复呈现。同一问题不在多个分区换句话重复生成。

切换日期或项目范围、任务与项目资料发生变化时会重新核对；相同资料复用本次运行期间的分析缓存。「重新分析」可强制请求模型。输出结构版本变化会使旧缓存失效。

点击任务的「帮我推进」，助理会结合当前任务、项目目标、依赖阻塞、跟进记录、已确认记忆及其可用原文给出推进建议和沟通草稿。可补充遇到的困难并重新分析，编辑的草稿自动保存在本机，后续分析保留用户编辑内容。复制后自行核对并发送。

每条建议可展开查看逐字引文，并可打开关联任务。分析只提出建议，不自动修改任务、排期或发送消息。新导入的资料沿用现有整理确认流程；不把尚未确认的候选直接视为项目事实。模型不可用、资料不足、调用失败或分析期间资料发生变化时显示具体状态，保留通用推进引导。

实现入口：`generate_today_brief`、`generate_task_coaching`。复用项目问答的检索与生命周期过滤，使用有界的多类型证据包；返回前校验引文、任务关联和快照时效。缓存按资料指纹、工作区恢复代次和模型配置版本隔离，最多保留48个结果。项目证据版本包含跟进、里程碑、项目目标和排期变化，保存未提交草稿不会触发模型分析。

验证：`cargo test -p project-assistant-core --lib assistance` 使用实际 Engine 和本机 HTTP 模拟模型验证资料引用、项目隔离、缓存复用、资料变化失效、只读行为及证据版本。模拟响应不代表真实模型输出质量。
