# 每日清单：整理任务与容量排期

每天进入“每日清单”，由你填写这一天可用的总分钟数，以及会议、临时事项的预留分钟数。容量不自动继承到次日；不填写时不能生成排期。时间按你的个人工作量计算，跟进他人交付只计算沟通和核对用时。

## 使用顺序

1. 选择全部项目或一个项目，填写并确认当天容量。
2. 点击“整理任务与依赖”。配置并允许模型读取资料后，可结合对应项目的飞书群/文档摘录、当前记忆和待确认任务提议，建议归并重复任务、关联进展、建立跟进任务、识别前置依赖、具体阻塞及估时。每项展示理由、原文逐字引文和变更影响。
3. 勾选需要采用的项并确认。默认没有勾选。未选项不生效；循环依赖或跨项目关系会拒绝整批操作。也可手动填写依赖、阻塞，预览确认后参与排期。
4. 核对“调整任务预计用时”，点击“按容量试排”。预览显示安排顺序、时间占用、先后条件、日期变化，以及每项未安排的原因。修改估时或勾选“本次暂不安排”后，必须重新试排再确认。
5. 点击“确认并应用排期”，才会保存日期、预计用时和顺序。清单保留每项确认时的排期依据；“查看其他事项”与任务池可查看未安排、阻塞及当天其他变化。

整理后最好再做试排；未确认的模型关系不会进入排期。如果没有模型，本地可识别同项目、同类型、同负责人、同标题的重复项和已有原文任务候选，并支持人工填写关系及容量排期。

## 排期规则

- 净容量 = 当天填写时间 − 会议/临时事项预留。分项目试排还会扣除其他项目当日已有安排，以及当天已经完成的安排，避免重复占用个人时间。查看全部项目可统一比较优先次序。
- 按截止紧迫性（包含后续交付期限）、可推动的后续工作、优先级及正在进行的工作排序。前置亲自执行任务先排，后续任务明确标记“先完成并确认前置任务”。
- 跟进任务排进今天，不代表他人已经交付，不会因此自动放行依赖该交付的工作。任务标记阻塞或存在未解除的具体阻塞时，暂不安排。
- 缺少估时时，执行任务暂按60分钟、跟进任务暂按15分钟试排，预览明确提示临时估算。确认排期即确认所列估时；可以先修改。估时不是实际工时。
- 按整项容纳，过长任务应先拆分；容量不足会保留待安排，不会擅自承诺明天或假设未来容量。已有更晚日期的任务保留原日期。
- 若原本安排在当天的任务被本次预览列为未排入，会明确显示“当天 → 待安排”；只有确认完整预览后才清空其计划日期。取消草案不改任务。

## 信息与确认边界

当前正式记忆参与分析，存在未解决冲突的记忆暂时排除。飞书原文只读取已接入、绑定项目的资料快照，同一远端对象使用最近成功采集版本；原文仍需核实。整理不会直接向飞书发消息，也不会改写项目记忆。

模型上下文包含完整范围内未结任务、截取的任务描述、最多80条当前记忆和100段近期飞书资料中的有界摘录（远端摘录共约16000字符）。页面提示材料可能不完整；大项目应分项目核对，不能将“没有建议”视为已经查完所有历史信息。每条建议必须引用实际发送给模型的材料，同项目且逐字匹配；未知引用或虚构引文整次拒绝。

任务归并会将来源任务标记取消并记录目标，保留其原有历史；目标任务负责人和日期保留，已确认依赖和阻塞随归并转移。关联原文任务提议会应用提议的状态与进度，预览展示前后值；新建默认是待核实的跟进任务。记忆中新建的任务不猜测负责人和期限。

任务版本、容量、估时、已确认关系、资料、记忆、模型配置或工作区还原发生变化后，未应用草案不能直接确认，需要重新生成。确认整批事务写入，失败不会部分调整。重复提交相同确认不会重复写入。
