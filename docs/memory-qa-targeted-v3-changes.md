## 首次生成对象筛选

`question-target-v4-conservative-target-projection`仅在明确单一Unit/Composite目标且原参考中存在兼容字面见证时，移除整条只描述相反对象、没有混合或不明语句的参考。比较、多目标、参数共享、StudyIntent、未知角色和混合正文不据此筛除；不从共现推断主任务身份。保留完整原参考Value、条件和顺序，不裁切不利条件。两个入口与控制器使用同一实际投影，模型索引和归一化严格指向实际供给参考；最终验证仍使用原快照。

## 明确错对象后的纠错

首个有效审查后，本地守卫明确发现答错目标且只有单一义务时，可以在一次真实本地检索后，从原先实际供给、尚未引用的兼容见证中选择最多6条完整参考，形成确实不同的引用子集，再生成和完整审查一次。它是已有事实的对象纠错，不计作发现新事实。原必要未知与因错对象失效的回答缺口必须逐项进入第二次审查，不能因新generation省略unknowns而消失；超过6项不截断放行。原始和当前两个快照均重新验证，失败保留原拒答或已审安全部分答案。

正常回答仍为2次模型请求；这条纠错路径通常为4次。没有明确兼容见证、多目标、协议错误、坏锚点或普通未决对象不触发该分支。

## 必要缺口的跨语与语义导航

对于有效、有据且直接回答了一部分的partial，若仍有原问题明确要求的缺口，本地定向检索又没有找到新的正向见证，可以使用一次受限目录改写。输入保留原问、必要缺口和当前短目录；目录与改写词只能导航。随后第三次真实检索必须带回新的、匹配必要缺口的当前事实，才允许追加生成和完整审查。未问细节、无法确定是否必要、unknown拒答或协议失败不能使用这条partial导航路径。原初始参考为空的导航例外保持原有独立条件。

有生成时这条路径最多5次模型请求；仅导航但没有新事实则不重复生成。它与对象纠错、普通新事实二生互斥。整体仍最多5次请求、3个真实检索轮、1次追加生成、24条聚焦参考/36000字符、180000累计输入字符及原输出、token止损和总超时上限。
