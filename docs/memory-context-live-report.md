直接核对的改善来自跨批后置条件和列表引导范围，两轮均复现。密集样本18个事实仍只保留12个；多做一次受相同输出上限约束的替换提取未补齐剩余6个。新版Atlas完整条件草稿旁边仍存在ready的无条件短候选，门禁需落实到每条事实及重叠窗口，不能仅按某批存在完整条件就放行其他候选。标题主体和表头字段关系仍未完整写入正文。

生产提取 token 消耗上升30.7%，请求上升13.3%；需要人工审核的候选由4增至36。当前结果支持“部分上下文组合改善”，不支持“普遍解决漏提”或“减少人工审核”。下一步应优先对饱和批次分区补提、关联处理重叠窗口中的不完整候选，并让审核门禁定位具体候选。
